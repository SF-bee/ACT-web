# ACT 动漫社网站

让热爱，在这里相遇。

明亮的蓝粉紫单页网站，包含社团介绍、CV / Cos 部门、往期招新海报展示与入社信息。原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。按 Control+C 停止服务器。

## 修改内容

- `index.html`：首页、社团介绍、导航及入社说明。
- `content.js`：部门文案、标签、公开展示版海报列表。
- `style.css`：配色、布局、动画与移动端适配。
- `app.js`：内容渲染、海报弹窗、滚动动画。
- `assets/`：可公开发布的素材。

海报为根据往期素材制作的公开展示版，使用图片编辑工具移除了旧联系方式、二维码和报名地点，细节与原件可能不同。原始海报只保存在本地忽略目录，不上传仓库。当前入社方式仍待补充。

## 发布

使用 GitHub Pages，从 `main` 分支根目录发布。`.nojekyll` 让静态文件直接发布。更新后推送到 `main` 即可触发部署。

网站不包含登录、报名数据收集或外部 API。

## 验证

已检查 320、390、768、1440 像素布局、海报加载、锚点导航、Enter 打开海报、Tab / Shift+Tab 焦点限制、Escape 关闭和焦点返回。支持系统「减少动态效果」设置；该设置目前完成代码审查，未切换设备系统偏好实测。
